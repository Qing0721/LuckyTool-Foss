## 题外话

我在这里对luckyzyx歪曲捏造事实的行为进行谴责，这个项目之所以存在不是因为遥测，黑名单或者后门，而是由于一个体量庞大的但违反开源协议的项目将会对社区造成极为不利的影响，

目前该项目的目的已经圆满达成，LuckyTool 现已经正式恢复了开源，结束了为期 4 年的违反开源协议的闭源开发，我很高兴看到我的工作有了巨大的成果
